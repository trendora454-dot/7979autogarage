## Түгээмэл засварууд

### 1. Үнэ солих

Ctrl+F → машины нэрээ хайна. Жишээ нь Toyota SAI-г 70,000-аас 80,000 болгох бол price гэсэн хэсгээс 70,000 гэдгийг 80,000 болгоно. **Зөвхөн тоог** сольж, тагийг бүү хөнд.

«Утсаар лавлана уу» болгох бол price ask ангилалтай хувилбарыг ашиглана.

### 2. Шинэ машин нэмэх

id="r1" (мөр 606) хэсэгт байгаа нэг мөрийг **бүтнээр нь хуулж**, доор нь буулгаад утгыг сольно.

- tag h → гибрид, зүгээр tag → энгийн
- b доторх нэр → зураг байхгүй үед харагдах нэр
- h3 → картын гарчиг, p → доорх тайлбар

**Зураг нь заавал нэмэгдэх ёстой:** мөр ~738-д байгаа IMG жагсаалтад **яг тэр байрлалд** нэр нэмнэ. Жагсаалтын дараалал картын дараалалтай **яг таарах ёстой**. Дараа нь images/ фолдерт тэр нэртэй зураг оруулна (Add file → Upload files).

Зураг байхгүй ч гэсэн сайт эвдрэхгүй — текст хувилбар нь харагдана.

### 3. Тосны үнэ / шинэ тос
